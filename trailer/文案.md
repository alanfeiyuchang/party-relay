# 宣传片文案（要改就改这一份）

片子里出现的所有字，加上小红书的标题和正文，全在这儿。直接在这份文件上改，
改完我按它回填到三个地方：

| 这份里的东西 | 真正生效的地方 |
| --- | --- |
| 旁白 | `trailer/voiceover.srt` |
| 画面上的字 | `PartyRelay/Trailer/TrailerCopy.swift` |
| 小红书标题 / 正文 / 话题 | `media/duo-video/发布.md` |

**几条硬约束**（别的随便改）：

- **旁白决定片长。** 最后一条的结束时间就是成片长度（现在 101.5 秒），改了它，
  `TrailerCanvas.duration` 和录制脚本里的 `DURATION` 要跟着改。
- **旁白的时间点决定画面的时间点。** 你可以只改措辞不动时间，那最省事；
  要是改了时长或者加减条数，我得把 `TrailerScenes.swift` 里每一段的秒数重新排一遍。
- **字数**：大标题单行 30pt，11 个汉字以内最舒服，超过 14 个会自动缩小；
  副标题 20pt，16 字以内；胶囊和列表项 14pt，8 字以内。超了不会截断，只会变小。
- 旁白是你自己念的，**不画在画面上**；画面上的字是另一套，两边不用逐字一致，
  但同一时刻说的和看到的得是同一件事。

## 小红书

**标题**（现用第一个）

```
1  折叠屏小白，怎么让一个游戏在 3 块屏上同时显示？
2  想用折叠 iPhone 的外屏？苹果只留了 1 条路，还得挂个假相机
3  一台折叠 iPhone，三个人各看一块屏，我是这么做出来的
```

**正文**

```
折叠 iPhone 出来之后我一直想试一件事：能不能让外屏也变成游戏的一部分。

我这个派对游戏本来是一台手机传来传去玩的，出题的人还得捂着屏幕。折成 90° 之后就不用了：
上半屏立着朝出题的人，只有他看得到词；下半屏平躺着正好当画板；外屏朝对面猜的人，
实时同步这幅画，答对还会报谁加分。

做完发现，这条路苹果只留了一扇窄门。

iOS 27 上想往外屏放自己的内容，公开 API 只有 UISceneAccessory。它两个工厂方法里，
一个是给 HDMI / AirPlay 外接屏的，另一个 cameraCapture 要求你「前台 + 有一个活跃的相机会话」。
不开会话，系统直接报 isAvailable = false，折到 90° 也没用。

所以现在这个画画游戏里跑着一个不显示、不保存、连帧都不读的 AVCaptureSession，
存在的唯一目的就是让系统放行外屏。代价是要申请相机权限、状态栏常亮绿点，上架还得写一段解释。

剩下的坑：折痕位置没有 API（只能按屏幕中线自己劈）、「笔记本模式」这个状态要自己从铰链角度推
（60–135° 算进，退出放宽到 50–145° 做滞回）、外屏右边有 84pt 用不了、内屏画板搬到外屏得自己按比例 fit，
不然左右各切掉四成。

真心希望以后苹果能把外屏开放给非相机类的 App —— 不然每个想用外屏的人，都得挂一个假的相机。
```
