# 小红书视频方案：iPhone Duo 外屏适配

> 渲染前先确认这一版。Blender 很贵，方案没拍板不开全片。

## 选题角度

不走「我做了个折叠屏游戏」（只会被点赞），走**方法贴**：把「想让自己的 App 用上折叠 iPhone 的外屏，目前只有一条路，而且要挂一个假相机」讲清楚。
这是独立开发赛道里几乎没人写过、但做 Duo 适配的人一定会搜的东西 —— 冲的是收藏，不是点赞。

## 可截图卡 ①：外屏唯一的那条路

> 这一段的措辞以 `PartyRelay/CoverScreen.swift` 顶部注释为准，别改写。

- iOS 27 想往外屏放自己的内容，公开 API 只有 `UISceneAccessory` 一条路
- 它只有两个工厂方法：
  - `externalNonInteractive` —— 是给 HDMI / AirPlay 外接显示器的
  - `cameraCapture` —— 门槛写死在头文件里：*"while the app is in the foreground and has an active camera capture session"*
- 真机实测：不开相机会话时系统报 `isAvailable = false`，折到 90° 也一样
- 所以 PartyRelay 开了一个**不显示、不保存、不读帧**的最小 `AVCaptureSession`：`.low` 画质，`VideoDataOutput` 设 `alwaysDiscardsLateVideoFrames`，代理收到帧直接扔
- 代价：相机权限、状态栏绿点、一点耗电，提交时还要在 App Review Notes 里解释「为什么一个画画游戏要相机」

## 可截图卡 ②：系统给你什么 / 不给你什么

| 想要的 | 系统给不给 |
|---|---|
| 折痕在屏幕上的位置 | ❌ 没有任何公开 API，只能假设折痕在正中，自己按屏幕中线劈 |
| 铰链角度 | ✅ `UIHinge`，但只有 closed / partiallyOpen / fullyOpen 四档 + 一个角度（实测折到 90° 读数 90.9°） |
| 「笔记本模式」这个状态 | ❌ 得自己定：60–135° 算进，退出放宽到 50–145° 做滞回，再等 0.3s 坐稳才换版 |
| 外屏能用多大 | 466×678pt，右边还有 84pt 系统安全区，真正能画的只有 382 宽 |
| 外屏自动镜像内屏 | ❌ 自己画。笔画存的是归一化坐标（单位是画板短边），直接搬过去会被切掉左右各四成，得按内屏画板的长宽比等比 fit |

## Blender 部分

- 两个 low poly 的人（简单几何体拼，不做脸），中间一张桌子，一台折成 90° 的手机
- 三块屏用模拟器出的截图 / 录屏贴材质
- 镜头：① 斜侧全景（钩子 + 封面）② 俯视三屏高亮 ③ 推近外屏（结尾）
- 脚本化生成（`scene.py`），工程和脚本都留在 `media/duo-video/` 下，可复跑

## 屏幕素材清单（都从模拟器取，真机没法截图）

| 要什么 | 怎么取 |
|---|---|
| 笔记本模式内屏 | `FORCE_LAPTOP=1` |
| 外屏画板镜像 | `PREVIEW_COVER=1 COVER_MODE=drawing` |
| 外屏答对报分 | 再加 `COVER_CELEBRATE=1`（轮流模式两行：`COVER_SCORERS=2`） |
| 外屏换词 | 再加 `COVER_CELEBRATE=skip` |
| 跳过相机弹窗 | `SKIP_CAMERA=1` |

## 正文草稿

> 折叠屏 iPhone 出来之后我一直想试一件事：能不能让外屏也变成游戏的一部分。
> 做完发现，这条路苹果只留了一扇窄门。
>
> 想往外屏放自己的内容，iOS 27 上只有 `UISceneAccessory`。它两个工厂方法里，一个是给 HDMI / AirPlay 外接屏的，另一个 `cameraCapture` 要求你「前台 + 有一个活跃的相机会话」。不开会话，系统直接报 `isAvailable = false`，折到 90° 也没用。
>
> 所以现在这个画画游戏里跑着一个不显示、不保存、连帧都不读的 `AVCaptureSession`，存在的唯一目的就是骗系统放行外屏。代价是要申请相机权限、状态栏常亮绿点，上架还得写一段解释。
>
> 剩下的坑：折痕位置没有 API（只能按屏幕中线自己劈）、「笔记本模式」这个状态要自己从铰链角度推、外屏的右边有 84pt 用不了、内屏画板搬到外屏得自己按比例 fit，不然左右各切掉四成。
>
> 真心希望以后苹果能把外屏开放给非相机类 App —— 不然每个想用外屏的人，都得挂一个假的相机会话。
